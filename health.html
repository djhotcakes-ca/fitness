Apple Health setup

✕
Websites can't reach Apple Health, so the app hands data to two Shortcuts you build once on this iPhone:
  • Fitness to Health logs new weight, BP, food (calories, protein, sodium) and optionally exercise.
  • Health to Fitness copies recent weight, BP and sleep so the app can paste them in.
Names must match exactly. Action names can differ slightly between iOS versions; search the action list for the bold names below. Takes about 20 minutes.

Tips for building

  • Type keys exactly: lowercase, and no space after them (autocorrect likes to add one).
  • Inside each loop, save v and d with Set Variable (e.g. wval, wdate) and use those names in Log Health Sample; both results are called “Dictionary Value” and are easy to mix up.
  • For the orange Dictionary in a later loop: tap the field → Select Variable → tap the bubble under “Get dictionary from” at the top.
  • Add an action: tap Search Actions at the bottom and type its name.
  • Pick a variable: tap a blue field, then choose from the list above the keyboard (e.g. Repeat Item, Dictionary Value).
  • Pick a property of a variable (like a sample's Start Date): insert the variable, tap it, and choose the property.
  • Build one loop fully, then long-press its Repeat action → Duplicate and edit the copy.

1 · “Fitness to Health”

  1. Shortcuts app → + → rename it Fitness to Health.
  2. Get Dictionary from Input, input = Shortcut Input. If Shortcuts asks what it receives, choose Text.
  3. Weight loop
    • Get Dictionary Value: get Value for key weight in Dictionary.
    • Repeat with Each item in that Dictionary Value. Inside it:
    • Get Dictionary Value: key v in Repeat Item.
    • Get Dictionary Value: key d in Repeat Item.
    • Log Health Sample: type Weight, value = the v value, unit lb, date = the d value.
  4. Blood pressure loop (skip it if a BP monitor app such as iHealth already writes to Health; it would log every reading twice. Use “Health to Fitness” to bring those readings into the app instead.) Otherwise: same pattern with key bp; inside, get s, dia and d. Log Health Sample type Blood Pressure: systolic = s, diastolic = dia, date = d. If your iOS only offers separate Systolic and Diastolic types, use two Log Health Sample actions.
  5. Food loops, four copies of the weight loop (keys v and d inside):
    • key kcal → type Dietary Energy, unit kcal
    • key protein → type Protein, unit g
    • key carbs → type Carbohydrates, unit g
    • key sodium → type Sodium, unit mg
  6. Exercise loop (optional): key workouts; inside get name, min, kcal, d. Log Workout: type Other (or Walking), start = d, duration = min minutes, energy = kcal. Some iOS versions save the wrong workout duration; check one in the Health app after the first run.
  7. Active Energy loop: key active; inside get v and d (e.g. aval, adate). Log Health Sample type Active Energy, unit kcal. The app only sends activities you did not mark “Already recorded by iPhone/Watch”, so walks your phone tracked aren't counted twice.
  8. Last action: Show Notification “Sent to Health”.

2 · “Health to Fitness”

  1. New shortcut, rename it Health to Fitness.
  2. Weight: Find Health Samples where type is Weight and start date is in the last 14 days. Then Repeat with Each sample; inside add Text:
    W|‹Start Date›|‹Value›|‹Unit›|‹Source›
    each ‹…› being a property of Repeat Item. Tap the Start Date token → Date Format: ISO 8601, include time on. Then Add to Variable, variable name Lines.
  3. Systolic: Find Health Samples, type Blood Pressure Systolic, last 30 days → Repeat → Text S|‹Start Date›|‹Value› → Add to Variable Lines.
  4. Diastolic: same with Blood Pressure Diastolic and Text D|‹Start Date›|‹Value›.
  5. Sleep: Find Health Samples, type Sleep Analysis, last 7 days → Repeat → Text Z|‹Start Date›|‹End Date›|‹Value›|‹Source› (both dates ISO 8601 with time) → Add to Variable Lines.
  6. Active Energy: Find Health Samples, type Active Energy, last 7 days, and add the filter Source is not Shortcuts; if it offers Group By, choose Day. → Repeat → Text E|‹Start Date›|‹Value›|‹Unit› (ISO 8601 date) → Add to Variable Lines. This leaves out the calories this app sent, because the app adds your logged exercise (like rowing) on top itself; that way nothing is lost or counted twice. Mark walks your iPhone/Watch tracked as “Already recorded by iPhone/Watch”. Older shortcuts that send A| lines still work, but Health's total then replaces your logged exercise.
  7. After the last loop: Combine Text Lines with New Lines → Copy to Clipboard → Show Notification “Copied, switch back to Balanced and tap Paste”.

Using it

  • ⇪ → Send … to Health runs the first shortcut. Swipe back to Balanced afterwards; it asks whether it finished so nothing is sent twice.
  • ⇪ → Pull … from Health runs the second; come back and tap Paste from Health. Readings the app already has are skipped, including ones it sent.
  • Pulled readings show as new like anything else you add here. Export as usual to merge them into the CSVs.
  • The first run of each shortcut asks for Health access; allow it. You can review it later in Settings → Health → Data Access & Devices → Shortcuts.
  • If Paste says it can't read the clipboard, long-press the box that appears and choose Paste.
